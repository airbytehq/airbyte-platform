# Connector documentation fixtures

These static snapshots cover the largest and most complex connector docs from
`airbytehq/airbyte`'s `docs/integrations`, taken from upstream commit
`6ee88a9bd15003bd9bd0158ca3a4e7720e2d5f2a`. They were chosen for size, link
count, admonitions, `<HideInUI>`, `<details>`, wide tables, and fenced code.

`stripe.md` is the document that hung `markdown-to-jsx` 7.7.4–7.7.17
(oncall #13443). These fixtures are not auto-updated; add a document here if
it exposes a new rendering problem.
